# ShooThem

Аркадный шутер с видом сверху: одна арена, десять волн, три единицы здоровья.
Чистые HTML, CSS, JavaScript ES modules; Canvas 2D и WebAudio. Никаких внешних ассетов, фреймворков, сборщиков или зависимостей игры.

## Запуск

Распакуйте архив, откройте терминал в папке ShooThem и выполните:

```sh
npx serve .
```

Откройте адрес, который напечатает сервер. Требуется Node.js с npm; первый запуск npx может потребовать интернет для загрузки serve. После запуска игра не обращается к внешним ресурсам.

Альтернатива с установленным Python:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Двойной щелчок по index.html не поддерживается: ES modules требуют HTTP-сервера из-за ограничений file:// в браузерах.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD или стрелки |
| Прицеливание | Мышь |
| Стрельба | Удерживать левую кнопку мыши над ареной |
| Пауза / продолжение | Esc |
| Звук | Кнопка в правом верхнем углу |
| Рестарт | «Играть снова» после завершения |

При потере фокуса или переключении вкладки включается пауза, нажатые клавиши сбрасываются. Звук активируется после нажатия кнопки запуска. Игра предназначена для клавиатуры и мыши; сенсорного управления нет.

## Правила

- Уничтожьте всех врагов в десяти волнах. Первая волна — 5 врагов, каждая следующая добавляет 2.
- Скорость врагов растёт с номером волны. Перед появлением врага виден круг предупреждения.
- Одно попадание уничтожает врага и приносит 100 очков.
- Контакт с врагом отнимает одно из трёх очков здоровья. После контакта действует неуязвимость 1,25 секунды; враг исчезает без начисления очков.
- Между волнами — 2,2 секунды. Последний уничтоженный враг десятой волны завершает игру победой.
- Нулевое здоровье означает поражение. Рестарт полностью сбрасывает текущую игру без перезагрузки страницы.
- Рекорд сохраняется при завершении матча в localStorage текущего браузера и origin. При запрете хранилища игра продолжает работать; рекорд остаётся в памяти до закрытия страницы. Смена адреса или порта сервера создаёт отдельное хранилище рекорда.

## Архитектура

- index.html, styles.css — оболочка, интерфейс и адаптивная вёрстка.
- src/main.js — инициализация, requestAnimationFrame, delta time, resize, потеря фокуса.
- src/game.js — состояния, симуляция update/step и отдельный render.
- src/config.js — размеры мира и параметры баланса, частота огня, волны, очки, лимиты эффектов.
- src/input.js — клавиатура и мышь.
- src/entities/ — игрок, пуля, враг.
- src/systems/ — волны, столкновения, звук и хранение рекорда.
- src/ui/screens.js — меню, HUD, пауза, победа и поражение.

Мир фиксированного размера вписывается в Canvas с сохранением пропорций. Размер окна не меняет скорость и расстояния; на узких окнах появляются поля. Координаты мыши преобразуются обратно в координаты мира. DPR ограничен 2, эффекты ограничены по количеству и времени жизни. Симуляция делится на подшаги до 1/120 секунды; траектория пули проверяется от предыдущей до новой позиции. Большие паузы между кадрами ограничены 50 мс, поэтому после зависания нет резкого скачка всей арены.

## Проверки

В среде разработки прошли:

- проверка синтаксиса каждого JS-файла и всех относительных импортов;
- создание игры и 600 циклов update/render с имитацией Canvas после каждого из семи этапов;
- движение по диагонали, пауза, стрельба, пересечение траектории пули с врагом;
- поражение, сброс состояния после рестарта, переход всех 10 волн до победы;
- сброс ввода, 1000 проверок безопасного появления врагов, недоступный localStorage;
- загрузка всех файлов по локальному HTTP в тестовом процессе.

Проверки логики: `node tests/logic.mjs` (Node.js 22+; сторонние пакеты не требуются). Тесты используют имитацию DOM/Canvas и не заменяют настоящий браузер.

**Ограничение проверки:** в среде выполнения отсутствует Chromium. Визуальный запуск, отсутствие ошибок именно в браузерной консоли, реальный звук и стабильные 60 FPS на среднем ноутбуке не подтверждены. Эти критерии нельзя считать закрытыми только по тестам логики.

Для ручной приёмки откройте игру в актуальном Chrome или Firefox: пройдите меню → игра → пауза → продолжение → поражение → рестарт, измените размер окна, переключите вкладку и проверьте сохранение рекорда после обновления. В DevTools проверьте Console и запись Performance на поздней волне; целевой бюджет кадра — 16,7 мс для экрана 60 Гц.
